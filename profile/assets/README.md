# Sharpie organization profile art

The ecosystem illustration is unique to the organization profile. Sharpie physically connects a server doorway, package module and client terminal. Mint green `#00DDB3`, ink `#17333E`, opaque white; native transparent background, flat fills and rounded white paws. No palette normalization was used. Source and lossless export details are in `sharpie-ecosystem.provenance.json`.

The screenshots in `../examples/` are local renders of the profile Markdown in desktop and mobile layouts, not screenshots of a published organization profile. The profile becomes visible after the PR is merged.
